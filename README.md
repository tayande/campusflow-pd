# CampusFlow
<2 to 3 sentences, in your own words: the problem it solves and what the program does>

- Campus flow is a command line program that allows learn2earn fellows to make their complaints to the coding mentors in such a way that they are all taken care of on their basis of urgency.
- In a campus like learn2earn, sometimes it gets difficult keeping and tracking all complains requiring the attention of the coding mentors, campus flow is here to help them keep proper record of each complain and attend to them appropriately.
- The most interesting part of the project is that complains are arranged and submitted with number of people or fellows that are affected and the coding mentors get to know which complain to treat as urgent and which not to.
